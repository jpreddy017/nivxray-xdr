## Envelope contract (must remain frontend-compatible)

Session-v1 keys populated from canonical projections:

| Key | Source |
|---|---|
| `session_id`         | `ses_` + short hash of ssot_ref (deterministic) |
| `created_at`         | `datetime.now(timezone.utc).isoformat()` (matches legacy) |
| `schema`             | `"session-v1"` (unchanged) |
| `original_input`     | `{raw, kind, label, confidence}` derived from `iue_decision` + `input_profile` |
| `document_profile`   | Passthrough of `ssot.input_profile` |
| `acquired_document`  | `{ok, url:None, ...}` derived from input_profile (legacy DIE web-fetch always populates when URL fetched; canonical branch fills `ok=True` on ready input, no vendor fetch in 5.1) |
| `investigation_inputs` | Derived from `project_iocs` + `project_lolbas` + `project_attck` (matches legacy shape) |
| `incident`           | Derived from `project_verdict` + `project_attack_story` (legacy R21-v3 shape) |
| `readiness`          | `incident.readiness` passthrough |
| `summary`            | Derived from `project_verdict` + `project_iocs` + `project_attck` |
| `raw_investigation`  | Full canonical projection view (equivalent role to legacy raw SSOT) |
| `summary_narrative`  | `None` (5.1 defers narrative builder; legacy sets it too when narrative fails). Analyst summary + executive summary already surfaced via `incident`. |
| `uil`                | `{kind, kind_label, ready, metadata, fragments}` (existing UIL provenance) |
| **`wave`**           | `"5.1"` **(NEW)** |
| **`lifecycle`**      | `"canonical"` **(NEW)** |
| **`canonical_ssot_ref`** | `"cssot:sha256:<fingerprint>"` **(NEW)** |
