## Post-authorisation bug fixes (2026-08-10)

- **Fix A · Front-door gating**: canonical branch no longer short-circuits on legacy UIL's `norm.ready` when the canonical executor already handles the kind (DOCX/PDF/ZIP/XML/HTML/etc.). Previously the DOCX upload returned `{"session": null}` immediately.
- **Fix B · Child-SSOT aggregation**: `build_canonical_session` now walks D6-r `child_ssot_ref` artifacts, resolves each child from the store, projects each child, and merges into the envelope. Previously the parent-only projections were empty for archive inputs — MITRE/Attack Chain/Recommendations all lived in children and were invisible in the session.
