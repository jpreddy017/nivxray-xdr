```

  ↓

  ↓
```

The Canonicalizer MUST always receive **complete** commands.

(bboxes are unioned across joined lines, confidence is the min

### 2.5 · P0.15C-5 · Vendor Regression Corpus  · v1
**Permanent** benchmark.  Every future release must pass.

```
Vendor Corpus v1
  · Talos       × 3
  · Securelist  × 3
  · Mandiant    × 2
  · Microsoft   × 2
  · Elastic     × 2
  · Huntress    × 2
  ────────────
    14 articles
```

For every article, assert:
* HTML extraction succeeds
* Images discovered  ≥ expected count
* OCR candidates selected  ≥ expected count
* Commands recovered  ≥ expected count
* OCR confidence recorded on every record
* Provenance preserved (all fields present · §4 below)
* Workspace investigation completes successfully
* Flag OFF → **byte-identical** to current production
* Flag ON  → **additive only** (never removes existing evidence)

Articles are pinned in the corpus manifest with a `sha256` of the
first-fetch HTML so the harness is deterministic even if the
article is later edited by the vendor.

## 3 · Release Gate Invariants  (all four MUST pass)

### 3.1 · Flag-OFF byte-identity
```python
assert acquire(url, flag=False) == baseline_snapshot(url)
```

### 3.2 · Additivity — VEEE never reduces evidence
```python
off = acquire(url, flag=False)
on  = acquire(url, flag=True)
assert len(on.structured_blocks) >= len(off.structured_blocks)
# Furthermore, every block in off must be present in on.
assert set(off.blocks) <= set(on.blocks)
```


## 4 · Mandatory OCR Provenance Schema

```jsonc
{
  "type":       "commandline" | "caption" | "ioc",
  "text":       "<recovered text>",
  "provenance": {
      "source":            "image",        // required
      "acquisition_level": "P3",           // required
      "image_url":         "https://…",    // required if fetched from URL
      "image_sha256":      "<hex>",        // required
      "bounding_box":      { "x": int, "y": int,
                             "w": int, "h": int }, // required
      "ocr_engine":        "tesseract-5",   // required
      "ocr_confidence":    0.0..1.0,        // required
      "veee_version":      "1.0",           // required
      "joined_from_lines": [1, 2, 3]        // required IF line-joining ran
  }
}
```

A schema validator (`services/veee/provenance_schema.py`) MUST
run inside VEEE before any record is emitted; on any missing
field the record is downgraded to a `skipped` provenance
breadcrumb with `reason="provenance_incomplete"`.
