## Resource and isolation assessment

Automatic traversal retains 16 KiB input, 128 KiB output per transition, 1 MiB
aggregate generated bytes, 64 visited/queued nodes, 12 layers and 12 returned
candidates. Signature-gated gzip/zlib streaming inflate enforces output and 128x
ratio limits (minimum 1 KiB allowance); CRC/format errors and incomplete/trailing
streams do not become fully decoded canonical evidence. Depth, malformed Base64,
bomb, truncation, CRC, branching, ambiguity and recipe-tampering regressions pass.

Two spawned workers per API process are allowed with no decoder-worker pending
queue; four-second polling timeout terminates/reaps an unresponsive child. Setup
cleanup, timeout reaping and capacity rejection are tested. Submitted content is
never evaluated as code. MITRE stays empty/HELD and provenance execution remains
false.

**Process isolation is not an OS sandbox.** There is no new cgroup/RLIMIT memory
cap, global admission/rate limit or restricted child credential/network profile.
Memory limits apply to generated artifacts, not total Python RSS or JSON/report
size. Imported modules and application-process count affect deployment memory.
The pipe polling timeout is not a separately enforced deadline around receiving
an already-started IPC message. Staging must validate CPU/RSS/IPC behavior under
concurrency and worker failure before making a stronger isolation claim.

### Reproducible legacy bypass (not a passing security gate)

Run `PYTHONPATH=backend python docs/research/command-intelligence/security_probes.py`.
Recorded output: [security-probe-results.json](security-probe-results.json).
The diagnostic allocates only a harmless 1 MiB buffer and delays a test thread
50 ms. It uses an ephemeral synthetic JWT and auth store, never live credentials.

| Probe | Automatic path | Legacy path |
| --- | --- | --- |
| 16,390-byte command (whoami plus spaces) | HTTP 422 | HTTP 200 with `automatic` omitted |
| 1,052-byte gzip expanding to 1,048,576 bytes | Output/ratio refusal | `GzipDecoder.decode` returns full 1 MiB |
| Thread work after 5 ms timeout | Spawned timeout has reaping regression | Helper returns 504, then the thread completes afterward |

Relevant paths: `routers/ops.py` command false/default branch, `/decode/magic`,
`/decode/smart` and `/recipe/run`; `routers/helpers/decode_offload.py`;
`decoders/gzip_stream.py`, `zlib_deflate.py`, `lzma_stream.py`; and legacy
`services/decoder/base/compression.py` implementations. In particular, zlib's
`bufsize` is an initial allocation hint, not an output cap. Some legacy detection
routines decompress before candidate selection. Source review establishes the
additional paths; the measured HTTP probe uses `/analyze/command`, while the
measured compression probe calls its shared legacy plugin directly.

Closure requires bounded codecs **during detection and decoding**, input/output
and aggregate budgets across all entry points, and killable execution/admission
control preserving legacy API contracts. Moving only the new page or merely
shortening the thread timeout does not close CI-09. These shared paths have other
product consumers; disabling them or changing their contracts without acceptance
would expand this repair beyond Command Intelligence.

## Authentication, tenants and evidence

The existing `get_current_user` dependency remains unchanged. Missing/invalid JWT
requests fail, synthetic users do not share cached reports, and actual Axios
requests keep the existing Authorization/tenant transport. Tenant changes cancel
requests and clear evidence; a late response cannot reappear. A 401 clears the
credential/result; busy errors remain visible. Pure analysis has no tenant DB
reads/writes or cross-request evidence cache. This does not establish deployed
MSSP/Administrator role or live Mongo tenant acceptance.

Exact original bytes (UTF-8 text), ordered intermediate inputs/outputs, source
spans, SHA-256 links, deterministic recipes, binary/text labels and alternative
candidates remain available. Only eligible complete text candidates are promoted.
IOC/token observations cite text evidence hashes and are not execution or
reputation verdicts. React renders evidence as escaped text. The UI now exposes
all unresolved limitations in a dedicated section and validates that array before
accepting the response. The frontend fixture was updated to satisfy that contract;
the initial missing-field test failure was repaired and the full suite rerun.
