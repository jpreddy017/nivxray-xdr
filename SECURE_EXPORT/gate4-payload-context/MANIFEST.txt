ROOT CAUSE (test/packaging context, NOT the rollback)
-----------------------------------------------------
The onedir service host is carried INSIDE the one-file artifact and is
located through sys._MEIPASS, which exists only in a PyInstaller
process. gate4_race.py imported the CHECKED-IN SOURCE MODULE under a
plain interpreter, so _service_payload_dir() returned None.
_stage_service_host() checked the payload BEFORE the RUNNING guard, so
the payload refusal fired first, the live-service protection was never
exercised, and the end-to-end section was never reached.

THE REPAIR (two causes, two fixes, nothing weakened)
----------------------------------------------------
1. agents/nivxforge-windows/nivxforge_setup.py
   _stage_service_host() answers "is something RUNNING here?" BEFORE
   "does this build carry a payload?". Both refusals are fail-closed and
   replace nothing; only the first is about the HOST. Both messages are
   kept verbatim.

2. .github/workflows/windows-sensor-installer.yml
   Gate 4 never asks the source module to stage. Every staging
   assertion runs the BUILT ARTIFACT (`stage-host`), and an artifact
   WITHOUT a payload now FAILS the gate explicitly instead of
   satisfying it. Added proof that could not be expressed before:
     · the service image is byte-identical (sha256) after the refusal
     · the service is still RUNNING after the refusal
     · the artifact CAN stage once - and only once - the stop and the
       image release are proved (GATE4 STAGE-AFTER-STOP)
   Every pre-existing GATE4 verdict is retained.

3. backend/tests/edr/test_p0_windows_reenrol_staging_race.py
   Four Linux regressions lock both halves:
     · a payload-less build facing a RUNNING service raises the RUNNING
       refusal and replaces nothing
     · it is still named as the wrong build once nothing is running
     · Gate 4 must drive stage-host through dist/ and must not call
       _stage_service_host() from the source module
     · Gate 4 must keep the byte-identical-image and still-RUNNING
       assertions and every GATE4 verdict string
